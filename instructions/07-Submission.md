# Submission

There is no code for you to write in this CHIP, but to earn credit for it you hand in the running app and answer the self-check questions.

* Make sure all the Cucumber scenarios pass: `bundle exec cucumber`.
* On Gradescope, submit your whole app: a zip of your repo, or the files themselves, including `config.ru`, `Gemfile`, and everything under `app/`, `bin/`, `config/`, and `features/`. The autograder starts your app itself and plays the game against it through its web pages, with one test for each of the Cucumber scenarios.
* Then answer the self-check questions on the next page.
